# 2026-09-20 · 0.1.1 修正与打包

用户授权：修复置顶状态及悬浮球开关后打包；随后追加标签/格式居中、音效库右键自动分配、
唱盘与 DJ 无缝切换。本记录是这些追加修改及当前包的新证据。

## 修改

- 图钉之前只改变 HWND 的置顶属性，绘制状态 `always_on_top` 一直保持默认 true，
  设置也未同步。现在共用一个显式处理失败的切换入口，同步 HWND、绘制状态和设置文件。
  激活为琥珀色竖直图钉，取消为灰色倾斜图钉；下次启动保留选择。
- 悬浮球上部以当前面板状态反向切换，收起仍走过渡动画；下部继续控制 BGM 暂停/恢复。
- `【】` 等前置括号标签，以及唱片台的“中·欢快”“MP3”等元数据，都使用居中对齐；
  保留超长文字省略及三个播放选项的预留空间。
- 唱盘/DJ 两项各宽 88 DIP，中间无缝直角，两端圆角；显示范围与切换命中边界一致。
- 唱盘模式右键 SFX 库卡片：选择第一个空音效台，全部占用时覆盖第 1 台；暂停及待加载
  台位仍视为占用。BGM 保持原播放，DJ 模式右键仍停止对应独立按钮。
