# 0.1.2：DPI 点击偏移、悬浮球立即关闭、底栏分类开关

日期：2026-09-20。基于当前工作树实测，保留此前未提交的功能改动；未创建提交。

## 原因与修正

- 主面板绘制使用当前窗口 DPI / 96 缩放，但 `application.cpp` 的 `to_ui_point`
  仅把 LONG 转成 float，没有反向换算。125%–200% 下，搜索框会命中分类或音乐卡，
  标题按钮会被当成拖动标题栏。此前纯 DPI 辅助函数测试通过，不能证明应用实际调用了换算。
- 现在所有面板输入经过同一个成员函数，以与渲染相同的窗口 DPI 换算，保留小数。
  覆盖 WM_NCHITTEST、悬停、光标、点击、拖放、音量、滚轮、搜索和波形定位。
  WM_DPICHANGED 取消旧捕获手势，尺寸变化后刷新鼠标位置；诊断日志记录物理坐标、DPI、逻辑坐标和命中 ID。
- 参考骰子项目的清单与“渲染 DPI 固定 96、只缩放一次”契约。音乐板保持逻辑布局，
  没有照搬骰子的物理布局坐标。三个 GUI 目标嵌入 PerMonitorV2 清单，启动即生效；
  ERROR_ACCESS_DENIED 仅在当前上下文确为 PerMonitorV2 时接受。
  从最终 EXE 用 SDK mt.exe 提取资源，确认清单实际嵌入；运行检查也确认窗口为 PerMonitorV2。
- 球上部关闭原先调用 420 ms 收起过渡，窗口一直等到过渡结束才隐藏。该入口现在在
  WM_LBUTTONUP 回调内 SW_HIDE，清除延迟隐藏状态。打开保留过渡，快速重新打开不会被旧计时器隐藏。
- 底部只读路径改为尾端对齐，靠近右侧两个曲库按钮。折叠按钮旁增加“显示全部”开关，
  默认关闭；同时控制 BGM/SFX 的“全部”标签。具体分类选择保持；原先选全部时切到第一项分类。
  开关变化重建标签宽度、行数、命中区域及列表，折叠宽窗/窄窗均无重叠。
  设置 schema 6 保存 `show_all_categories`，schema 5 升级默认关闭并保留原设置。

相关平台依据：[Windows 鼠标像素与 DIP](https://learn.microsoft.com/en-us/windows/win32/learnwin32/dpi-and-device-independent-pixels)、
[DPI 初始化与 ERROR_ACCESS_DENIED](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setprocessdpiawarenesscontext)。
