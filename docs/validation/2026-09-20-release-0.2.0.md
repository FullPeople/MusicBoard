# MusicBoard 0.2.0 validation — 2026-09-20

This release replaces Restart with Mix, implements audible playback fades, removes
effect-deck number/hotkey hints, and adds persistent CN/EN interface switching.
The implementation uses two bounded BGM voices and absolute-time gain envelopes.
Mix uses a 2.5-second equal-power crossfade; Fade without Mix waits for the outgoing
fade before starting the incoming fade. Track names and user categories keep their
original language.

The constant-power transition concept was checked against the
[Mixxx control documentation](https://manual.mixxx.org/2.5/en/chapters/appendix/mixxx_controls).
No third-party application source code was copied for the transition.

## Measured audio behavior

`tools/audio_transition_probe.cpp` produces known tones and
`tools/verify_audio_output.py` measures their amplitudes from WASAPI loopback.
Only frequency measurements are saved; no raw desktop recording is written.

- Pause fade reached zero output; resume ramped back up.
- Crossfade midpoint: outgoing amplitude 0.710608, incoming amplitude 0.702902,
  relative combined power 0.999034. Both sources reached the output concurrently.
- Stop faded to silence; the outgoing BGM voice was reclaimed.
- A non-looping effect faded at its natural ending.
- With Mix off, the incoming track waited for the outgoing fade.
- Engine tests also cover pause reversal, pausing a delayed incoming voice,
  immediate controls with Fade off, seeking/looping during a natural-end fade,
  and shortening an existing crossfade tail when stopping.

An English-language restart loaded the already cached 491-track library in
2.010 seconds (2.172 seconds measured by the launcher), with 178.30 MiB resident
preload data. This is a warm-cache measurement, not a cold-load guarantee.

## Reproduction

Build and run CTest using the presets in README.md. Set
`MUSICBOARD_TEST_LIBRARY` to a local BGM/SFX library to enable real-file cases.
Use `MusicBoard.exe --selftest` for application checks. The Python drivers under
`tools/` expose their required arguments with `--help`; interactive checks need
a Windows desktop and the output measurement needs an audio endpoint, NumPy
and PyAudioWPatch. Missing external test fixtures are reported as SKIP.

The GitHub workflow independently builds, tests and packages the exported source
on Windows. Its actual status is available in the repository's Actions tab;
these local results are not a substitute for that run.

The first clean-runner build succeeded, but `core_tests` terminated immediately
after its third assertion. A legacy test demonstrated encoding differences by
calling `path.string()` on a Chinese filename and assumed a Chinese system code
page. This conversion cannot represent the name on the runner's system locale.
The test now asserts an independently authored exact UTF-8 result and explicit
four-byte UTF-8 for a supplementary character, without invoking the forbidden
locale-dependent conversion. This fix changes test code only; the packaged
application and its output measurements are unchanged.
