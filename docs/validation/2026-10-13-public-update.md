# MusicBoard 0.3.2 公网更新验收

0.3.2 已在 GitHub 和 dnd.center 公开发布。Windows 安装版、便携版和开源代码入口已更新到官网详情；macOS 仍标注为待发布。

## 真实升级

使用独立测试目录安装真实 0.3.1，运行其原生应用，走应用启动时的更新检查。公共 HTTPS 清单验证签名后发现 0.3.2；更新窗口下载并核对了正式安装器的全部字节。应用仍运行时点击安装，窗口明确要求退出；旧程序正常退出后，新安装器在同一目录完成升级。随后启动新版本查询、再次检查最新版本，并正常卸载。

17 项通过，包括真实设置文件 `settings.conf` 和独立曲库保留、临时更新程序清理、卸载登记与开始菜单移除、升级后的版本和主程序摘要。测试没有使用用户安装目录或真实曲库。证据位于本机隔离的 `FullTools-QA/update-11baf73f4b8544afadf3fb8d0381bc5b/report.json`。

较早探针错误查找 JSON 设置文件，修正为产品实际使用的 `settings.conf` 后重跑。另一次探针关闭已销毁窗口时遇到 Win32 1400，补充了关闭期间的生命周期处理并重新完成整组测试；没有把中断的检查算作通过。网络较慢时，早期 150 秒测试上限不够下载完整包，后续允许 600 秒等待；签名、大小和摘要要求保持不变。
