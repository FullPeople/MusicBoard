# Windows 0.3.0 更新与安装包

- 通知区域和悬浮球菜单增加“检查更新…”。主界面显示后延迟 10 秒启动后台检查，组件按产品记录每日最多一次的检查时间。
- 更新由 FullOffice 开源库中的独立原生组件完成：验证更新清单签名、下载大小和摘要，安装前要求退出音乐板；组件先复制到暂存目录运行。
- 更新组件包含在包内的文件校验清单中。后台失败不弹出窗口，主动检查提供结果与重试入口。
- 最新 0.3.0 ZIP 重新完成 21 项实际安装、卸载、篡改拒绝和用户数据保留检查。音乐板与安装器继续使用自己的橙色图标。
- 右键“导入音乐链接…”和 Ctrl+U 保留进度、取消、重复导入、自动播放和本地保留选项。

公共更新源发布、实际跨版本升级、真实平台链接播放、第三方下载工具完整发布资料与 macOS 包体仍需继续验收。
