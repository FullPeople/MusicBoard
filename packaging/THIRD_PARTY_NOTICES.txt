--------------------------------------------------------------------
Windows platform components
--------------------------------------------------------------------
The executable links only against operating-system components that ship with
Windows: Direct3D 11, DXGI, DirectComposition, Direct2D, DirectWrite, Windows
Imaging Component, XAudio2, Media Foundation, WinHTTP, CNG (bcrypt), Shell32,
Ole32, User32, Gdi32, Kernel32, Dbgihelp and Psapi. The main application uses the Windows audio runtime. No Visual C++
redistributable is required (the C runtime is linked statically). URL imports
use the separate bundled media tools listed below.

--------------------------------------------------------------------
No audio content is bundled
--------------------------------------------------------------------
The installer and the application contain no music or sound effects. You point
the application at your own library folder; it reads those files and never
copies or uploads them.

--------------------------------------------------------------------
Bundled URL import components
--------------------------------------------------------------------
yt-dlp 2026.08.19 is distributed unmodified as a separate executable. Its
license and third-party notices are included in media-tools/licenses.
Project: https://github.com/yt-dlp/yt-dlp

FFmpeg 9.0.2 is built as shared LGPL 2.1+ libraries, with LAME 4.0 for MP3
encoding. The source-matched build is invoked as a separate conversion
process. License texts are included in media-tools/licenses. Original source
archives, release verification materials and build recipes are included in
media-tools/sources/MusicBoard-media-corresponding-source.zip. URLs, versions,
configure options and file hashes are recorded in media-tools/provenance.json.
Users may rebuild or replace this component with a compatible runtime.
Project: https://ffmpeg.org/
MP3 encoder: https://lame.sourceforge.io/

The FullTools single-track adapters in media-tools/plugins are MusicBoard
source code under the root LICENSE.txt. They request public playback URLs and
report provider access refusals. They do not use browser cookies or bypass
account, region, subscription or DRM requirements.
